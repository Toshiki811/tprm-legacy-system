# TPRM レガシーシステム UI モック

社内の **帝国評点管理システム** と **サードパーティ情報管理システム** のデモ用画面モックです。
AIエージェントによる画面自動操作のデモを想定して作成されています。

---

## 画面一覧

| URL | 画面名 |
|-----|--------|
| `http://localhost:5000/` | TPRMオンボーディング支援システム（メインメニュー） |
| `http://localhost:5000/teikoku-search` | 帝国データバンク 評点照会システム |
| `http://localhost:5000/thirdparty-entry` | サードパーティ情報管理システム（新規登録） |

---

## 動作環境の前提条件

以下のソフトウェアが PC にインストールされている必要があります。

### 1. Node.js（バージョン 18 以上）

**インストールされているか確認する方法：**
ターミナル（Mac）またはコマンドプロンプト（Windows）を開いて以下を入力してください。

```
node -v
```

`v18.0.0` のようなバージョン番号が表示されれば OK です。
表示されない場合は https://nodejs.org/ja から **LTS版** をダウンロードしてインストールしてください。

## セットアップ手順（初回のみ）

### ステップ 1：リポジトリをクローンする

ターミナルを開いて以下を順番に実行してください。

```bash
# デスクトップに移動
cd ~/Desktop

# リポジトリをクローン（URLは実際のリポジトリURLに置き換えてください）
git clone https://github.com/YOUR_ORG/tprm-legacy-system.git

# クローンしたフォルダに移動
cd tprm-legacy-system
```

> **ターミナルの開き方（Mac）**
> `Cmd + Space` を押して「ターミナル」と検索 → Enter

> **ターミナルの開き方（Windows）**
> スタートメニューから「コマンドプロンプト」または「PowerShell」を検索して開く

---

### ステップ 2：依存パッケージをインストールする

クローンしたフォルダ内で以下を実行します。

```bash
npm install
```

`node_modules` フォルダが作成されれば成功です。
（初回は数分かかる場合があります）

---

## 起動方法（毎回）

```bash
# プロジェクトフォルダに移動（ステップ1の cd が済んでいれば不要）
cd ~/Desktop/tprm-legacy-system

# 開発サーバーを起動
npm run dev
```

起動に成功すると以下のようなメッセージが表示されます。

```
▲ Next.js 15.x.x
- Local: http://localhost:5000
✓ Ready in xxxms
```

ブラウザで `http://localhost:5000` を開いてください。

---

## 停止方法

ターミナルで `Ctrl + C` を押すとサーバーが停止します。

## トラブルシューティング

### `npm install` でエラーが出る

Node.js のバージョンが古い可能性があります。`node -v` でバージョンを確認し、18以上でない場合は再インストールしてください。

### `npm run dev` でポート5000が使用中と出る

別のアプリがポート5000を使っています。以下のように別のポートで起動できます。

```bash
npx next dev -p 5001
```

その場合は `http://localhost:5001` でアクセスしてください。

### `git clone` で認証エラーが出る

GitHub のアクセス権限が必要です。リポジトリのオーナーに招待してもらうか、SSH鍵の設定が必要な場合があります。管理者にお問い合わせください。
